# README artwork

`readme-hero.webp` is original conceptual documentation artwork generated with OpenAI’s built-in image-generation tool on October 14, 2026. It is not a product screenshot, a real project photograph, or a replacement for an existing application logo. No private records were used as visual inputs.

## Prompt

Original premium GitHub README hero banner, wide landscape 3:1. Magnifying lens over stylized city map grid, map pin and organized data cards. Cream, petrol blue, orange. No real locations, identifiers, businesses, Google branding. Editorial dimensional illustration with rich material detail, generous negative space. Exact title "Business Profile Workbench" large high-contrast beautifully typeset left, illustration right. Readable on phone. No other text, badges, people, metrics, fake screenshot. Opaque background.

## Preparation

The selected original was proportionally resized to 1600 pixels wide and encoded as WebP at quality 86. Existing project and application assets were left unchanged.
